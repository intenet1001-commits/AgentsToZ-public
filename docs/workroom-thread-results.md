# 업무 스레드의 워크룸 결과 수집

공동 업무는 프로젝트마다 독립 워크룸을 열고, 각 프로젝트의 질문·진행·결과를 같은 부모 업무 스레드에 기록한다. 승인된 Mac·휴대폰은 기존 프로젝트 권한 검사와 암호화 workspace 경로로 같은 기록을 읽는다.

Codex·Claude의 완료 답변은 AI가 게시 도구를 호출하지 않아도 호스트가 이미 관찰하는 CLI 완료 기록에서 수집한다. Codex의 `task_complete.last_agent_message`, Claude의 주 대화 `end_turn` 내 공개 text 블록만 대상이다. 도구 입출력·추론·하위 에이전트 기록·화면의 일반 문자열은 결과로 복사하지 않는다. 기존 계정·프로세스·프로젝트 결속과 제한 세션 제외, JSONL 읽기 예산을 유지한다. Hermes와 agy의 결과는 기존 명시적 게시 도구 경로를 사용한다.

완료 기록이 현재 입력에 속하고 실제 요청 전송이 확인된 경우만 완료 처리한다. 새 입력·종료·폴더 변경·미확정 전송은 이전 답변으로 완료 처리하지 않는다. 게시 도구와 완료 관찰이 겹쳐도 같은 결과를 중복 기록하지 않는다. 저장 오류 시 최대 12KB의 공개 답변 하나만 15초 간격으로 재시도하며, AI 요청을 재전송하지 않는다. 더 긴 응답은 스레드에 잘림 안내를 남기고 연결 워크룸에서 전체를 확인한다. 이 기록은 프로젝트 장기기억 저장 동의를 대신하지 않는다.

회귀 검사는 완료 파싱·입력 경합·저장 재시도·두 프로젝트의 부모 스레드 집계·중복 게시·모바일 transport 정규화를 검사하며 실제 Claude 추론은 실행하지 않는다.
