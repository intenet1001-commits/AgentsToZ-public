# 팀 작전

한 작업을 여러 AI에게 나눠 맡기고, 지금 쓰고 있는 AI가 리더로서 결과를 모아 마무리합니다.
Claude Code로 연 워크룸이면 Claude가, Codex로 열었으면 Codex가 리더입니다 — 어느 AI든 리더가 될 수 있습니다.

## 시작하기

- **워크룸에서**: 입력창 위의 **팀 작전**을 누릅니다. 목표를 적고 팀원(AI, 원하면 모델, 맡길 작업)을 고른 뒤
  **지시문 넣기**를 누르면 리더 지시문이 입력칸에 채워집니다. 확인하고 보내면 시작합니다.
- **업무 스레드에서**: 새 업무의 **작업 AI**가 리더입니다. 옆의 **팀 작전**으로 같은 방식으로 구성합니다.
- 말로 시켜도 됩니다: 「Codex는 서버, Antigravity는 화면, Hermes(Claude 모델)는 테스트로 나눠서 진행해」.
  모든 AI에 `agentstoz-team` 스킬이 설치되어 있어 같은 순서를 따릅니다.

팀원은 1–6명입니다. 모델은 비워 두면 각 CLI의 기본 모델이고, Hermes는 Claude 계열·OpenAI 계열 모델을 모두 쓸 수 있어
모델과 함께 provider(예: `anthropic`, `openai-codex`)를 적을 수 있습니다.

## 진행 방식

1. 리더가 코드를 읽고 겹치지 않는 작업으로 나눕니다. 시작 전에 리더 쪽 변경을 커밋합니다 — 팀원은 리더 체크아웃의 지금 HEAD에서 시작하고,
   커밋되지 않은 변경이 있으면 팀이 시작되지 않습니다.
2. 팀원마다 새 워크트리(`worktrees/team-…`)와 브랜치(`team/…`)가 만들어지고, 그 안에서 지정한 AI의 워크룸이 열립니다.
   작업 세션 목록에서 각 팀원의 화면을 볼 수 있습니다.
3. 팀원은 자기 브랜치에만 커밋하고, 끝나면 리더에게 보고합니다(바꾼 것·커밋·검사 결과). 막히면 질문을 보냅니다.
4. 리더가 각 브랜치를 검토해 병합하고 검사합니다. 충돌은 리더가 해결합니다.
5. 리더가 팀을 정리합니다. 팀원 워크룸을 닫고 깨끗한 워크트리와 병합된 브랜치를 지웁니다.
   **커밋되지 않은 작업이 남은 워크트리와 병합되지 않은 브랜치는 지우지 않고** 알려 줍니다.

어떤 단계에서도 push하지 않습니다. 팀원의 보고는 결과의 증거가 아니라서, 리더가 diff와 검사로 확인합니다.

## 알아 둘 것

- 이 Mac의 AI 연결에서만 동작합니다(휴대폰·웹에서 팀을 만들지 않습니다).
- 의존성(`node_modules` 등)은 워크트리마다 따로라서, 팀원이 필요하면 직접 설치합니다.
- 실행 중인 워크룸은 최대 12개입니다. 팀원이 많으면 다른 세션을 먼저 닫으세요.
- 같은 요청을 다시 보내도 팀원이 두 번 시작되지 않습니다. 시작에 실패한 팀원은 실패로 남고 자동으로 다시 시도하지 않습니다.
- 앱이 워크트리에 복사해 넣은 설정(`.claude/`, `.env`)은 팀원의 작업으로 치지 않습니다. 원본과 똑같으면 정리할 때 함께 지우고,
  팀원이 고쳤으면 그 워크트리를 남깁니다.
- 권한 우회 없이 연 워크룸은 평소처럼 승인을 묻습니다. 리더의 도구 호출과, Codex 팀원의 커밋(작업 폴더 밖인 `.git`에 쓰기)이 그렇습니다.
  팀원은 리더의 권한을 물려받지 않습니다.
- AgentsToZ를 업데이트한 뒤에는 Hermes 앱을 한 번 다시 시작하세요. 그 전까지 Hermes 팀원은 보고 도구를 보지 못하고
  자기 화면에만 결과를 적습니다(리더가 화면을 읽어 확인합니다).
