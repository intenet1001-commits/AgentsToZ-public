# 인터넷 워크룸 전체 승인

인터넷 QR 연결 승인 화면의 허용 범위에서 **현재 등록된 전체 프로젝트·워크트리**를 선택하면 표시된 목록의 모든 runtime target ID를 하나의 기기 권한으로 저장한다.

- 확인된 대상이 1~256개이면 전체 선택을 제공한다. 중복 등록·Git 조회 실패 등으로 목록이 불완전해도 개별 검증된 대상은 승인할 수 있다. 이 경우 ‘현재 확인된 전체’와 제외 안내를 표시하며, 조회되지 않은 대상까지 승인했다고 표시하지 않는다.
- 이후 추가된 프로젝트·워크트리는 포함하지 않는다. 작업 폴더 선택의 ‘이 기기가 새로 만든 프로젝트’ 권한과 구분한다.
- SAS 확인, 연결별 최대 30일 유효기간, 재연결·앱 재시작 복원, 명시적 해지 처리는 기존과 같다.
- CLI 입력·출력 승인이다. 기록 조회·기억 저장·대직 관리 등 별도 모바일 workspace scope를 함께 부여하지 않는다.
- 서버는 저장 시 모든 ID가 현재 등록된 대상인지 다시 확인한다. 일부만 저장하거나 실패를 성공으로 표시하지 않는다.

검증: `tests/workroom-approval-scope.test.ts`, `tests/internet-workroom-approval.e2e.mjs`.
