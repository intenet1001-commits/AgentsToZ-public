# UI 용어집 (화면에 보이는 말)

같은 것을 여러 이름으로 부르면 처음 쓰는 사람은 그것을 서로 다른 기능으로 읽는다.
감사(2026-09-25)에서 한 기능이 다섯 이름(AgentsToZ OPS / OPS 음성 / 총괄 / 아젠투지 호출 /
운영 프로필)으로, 한 개념이 두 이름(단말·기기)으로 흩어져 있었다. 화면 문구는 아래 표 하나를 따른다.

`tests/ui-glossary.test.ts`가 이 규칙을 소스에서 검사한다. **test id·`data-help-key`·코드 식별자·
저장 키·와이어 형식은 바꾸지 않는다** — 이 표는 사람이 읽는 문구에만 적용된다.

| 개념 | 화면에 쓰는 말 | 쓰지 않는 말 | 비고 |
|---|---|---|---|
| 사용자 운영 비서(OPS 프로필·음성·호출) | **아젠투지** | AgentsToZ OPS, OPS 음성, 운영 프로필(제목으로) | 역할을 구분해야 하는 설명문에서는 「아젠투지(OPS)」. 사이드바 역할 칩은 별도 작업 소유. 음성 도크에서 **대화 상대**를 구분할 때만 「총괄」(아젠투지 OPS가 직접 답함)과 「담당자」(프로젝트 워크룸 AI)를 쓴다 — 제품 이름·제목은 여전히 아젠투지 (VOC 2026-09-29) |
| AI와 함께 작업하는 터미널 화면 | **워크룸** | Workroom | 코드 식별자(`Workroom*`)는 그대로 |
| Mac·PC·서버 한 대 | **기기** | 단말 | Mac만 가리킬 때는 「이 Mac」도 쓸 수 있다 |
| Supabase로 보내기 / 가져오기 | **올리기 (Push)** / **받기 (Pull)** | 단독 「Push」「Pull」 버튼 이름 | 괄호 안 영어는 익숙한 사용자를 위한 보조. Git의 Push/Pull(브랜치 동기화)은 Git 용어 그대로 둔다 |
| 프로젝트 등록 행에서 나온 8자 식별값 | **프로젝트 코드** | 해시, 로컬프로젝트해시(라벨로) | 클립보드의 `[로컬프로젝트해시: …]` 표기는 Telegram·라우팅이 파싱하는 **와이어 형식**이라 바꾸지 않는다 |
| AI가 묻지 않고 파일 수정·명령 실행 | **승인 없이 실행 (권한 우회)** | Bypass ON/OFF | 켜져 있으면 `--warn` 색으로 표시 |
| 워크룸에서 AI와 하는 한 건의 일 | **작업** (시작 전) / **작업 세션** (실행 중) | 「새 터미널」·「세션」을 버튼 이름으로 | 한 기능이 버튼에서는 「새 터미널」, 목록에서는 「작업 세션」, 입력칸에서는 「작업 요청」이라 처음 쓰는 사람이 서로 다른 것으로 읽었다(VOC 2026-10-05). 「터미널」은 **CLI가 그려지는 화면 영역**에만 쓴다 — 「하단 터미널 펼치기」·「터미널 직접 입력」·「터미널이 종료되었습니다」는 그대로. aria-label(`터미널 프로젝트`·`터미널 AI`)과 test id는 바꾸지 않는다 |

## 문구를 쓸 때

- 새 화면 문구가 위 표의 「쓰지 않는 말」을 쓰면 용어집 테스트가 실패한다. 표에 없는 새 개념이
  둘 이상의 이름으로 불리기 시작하면 여기에 행을 추가하고 테스트에도 규칙을 넣는다.
- 한국어 조사를 함께 고친다: 단말은 → 기기는, 단말이 → 기기가, 단말을 → 기기를, 단말과 → 기기와.
- SQL 마이그레이션(`supabase/migrations/*`)과 그 사본(`src/*Sql.ts`, `src/schemaSql.ts`)은 이미
  적용된 DB 정의라 이 작업에서 고치지 않는다. DB가 직접 만드는 기본 기기 이름(`'단말 '||…`)은
  다음 마이그레이션에서 함께 바꿀 대상이다.
