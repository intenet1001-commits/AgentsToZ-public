# 내 프로필과 사용자 지시 기록

사람의 선호는 **장기기억 → 내 프로필**, 지시 원문과 연결된 결과는 **내가 한 말**에서 관리한다.
아젠투지 설정의 OPS 운영 기억은 프로젝트 별칭·관계·에이전트의 일하는 방식이며, 개인 프로필과 별도다.

| 내용 | 정본 | 사용 방식 |
|---|---|---|
| 직접 확인한 선호 | 내 프로필의 암호화 로컬 저장소 하나 | 전체 프로젝트 또는 지정 프로젝트에만 적용. 현재 지시가 우선 |
| 과거 지시 원문과 입력 경로 | 기존 프로젝트별 What I Said 저장소 | 시각·출처가 있는 과거 근거. 확정 선호로 자동 승격하지 않음 |
| 프로젝트 설계·수정·검증 경험 | 각 프로젝트의 기존 장기기억 | 해당 프로젝트의 다음 작업에 활용 |
| OPS 운영 방식·프로젝트 관계 | 기존 OPS 운영 기억 | 기존 후보 제출·사람 검토 계약 유지 |
| 여러 프로젝트에 연결한 지식 | 기존 공통기억 | 명시된 연결 범위에서 회상. 개인 프로필의 자동 공유 수단으로 사용하지 않음 |

## 첫 구현의 범위

- 데스크톱 앱에서 **내 프로필 열기**를 눌러야 읽는다. 장기기억 화면을 보는 것만으로 개인 프로필을 준비하거나 키를 만들지 않는다.
- 항목의 제목·선호·적용 범위를 직접 정리하고 확인한 뒤 저장한다. 원문 화면과 프로필 사이에 이동할 수 있으며, 원문을 프로필로 복사하거나 과거 대화를 자동 분석하는 기능은 없다.
- 선호를 수정하거나 **사용 중지 / 다시 사용**할 수 있다. 사용 중지 상태를 저장하면 다음 AI 회상부터 제외되며 저장소에는 복원 가능하게 남는다. 이것을 영구 삭제라고 표시하지 않는다.
- 첫 저장부터 전용 키와 암호화 파일을 쓴다. 기존 프롬프트·음성·What I Said 키를 공유하지 않는다. 누락·잠금·손상된 기존 키와 파일을 새 프로필로 덮어쓰지 않는다.
- 읽기와 저장은 현재 OS 사용자의 이 기기 로컬 범위다. Supabase service-role 설정, OPS `profileId`, 프로젝트 `memoryId`를 사람의 계정 ID로 간주하지 않는다. 계정 전체·기기 간 동기화, 모바일·릴레이 접근은 구현하지 않았다.
- 모든 저장은 신선한 revision으로 충돌을 검사한다. 실패하면 작성 내용을 유지하며, 결과를 모르는 저장을 새 요청으로 자동 재실행하지 않는다.
- 동시 편집은 기존 저장본·초안·최신 저장본을 항목 ID로 비교한다. 다른 창의 새 항목과 별도 항목 변경은 보존하고, 같은 항목이 양쪽에서 바뀌면 실제 내용·적용 범위·사용 상태를 비교해 직접 선택한 뒤 저장한다.
- `origin: user-confirmed`는 앱에서 확인 저장한 항목이라는 뜻이다. 작성자의 생체 인증이나 사람이 직접 입력했다는 증명이 아니다. 같은 OS 사용자 권한의 로컬 코드는 신뢰 경계 안에 있다.

## AI 조회

`agentstoz_use_recall_user_profile({portId, query})`는 연결된 OPS 인증과 정확한 등록 프로젝트를 확인한 뒤
그 프로젝트에 적용되는 활성 선호만 읽는다. `userProfile` 데이터는 최대 5개, JSON UTF-8 8,000 bytes이며 빠진 항목은
`truncated`로 알린다. 조회는 원문을 수집하거나 AI를 호출하거나 항목을 저장하지 않는다.

과거 원문은 기존 `agentstoz_use_recall_user_memory`로 별도 조회한다. 두 결과를 근거와 선호로 구분하고,
현재 명시한 지시를 우선한다. 프로필의 문장을 실행 권한으로 해석하거나 모델·계정·승인 모드를 자동 변경하지 않는다.

## 후속 확장 조건

AI가 정리한 후보나 원문 선택 저장을 추가할 때는 먼저 출처 `(memoryId, eventId, hash)`와 확인 시각을
결속하고 원문 삭제·보관 기간 만료에 따른 후보 무효화를 구현해야 한다. 현재 원문 삭제 계약과 충돌하는
대화 사본을 새로 만들지 않는다. 직접 재확인한 독립 선호의 보존과 AI 추론의 폐기는 화면에서도 구분해야 한다.

기기 간 공유는 검증된 사람의 계정 바인딩·별도 동의·충돌/철회/삭제 전파를 먼저 설계한다. 공통기억에
연결하거나 OPS 기억에 합치는 것으로 대신하지 않는다. 첫 구현에는 이 자동 공유 경로가 없다.
