# 아젠투지 헬프데스크

아젠투지 헬프데스크는 처음 설치하는 사람에게 필요한 프로그램, 공식 계정 인증, 본인 데이터 저장소, AI 연결과 사용법을 한 단계씩 안내합니다. **아젠투지 호출** 창 오른쪽 위의 **헬프데스크**를 누르세요. **처음 설치해요**, **사용법이 궁금해요**, **문제가 생겼어요**에서 시작할 수 있습니다.

이 문서는 최신 Mac 소스 기준입니다. 현재 공개 다운로드 v1165는 [해당 버전 설치 안내](MAC-INSTALL.md)를 따르세요. 필수 서비스 계정과 전용 저장소 자동 준비를 포함한 전체 첫 설치는 후속 빌드용입니다. [새 Mac 따라 하기](MAC-NEWCOMER.md) · [전체 가이드](GUIDE.md)

## 사용자 프로필은 어디에 있나요?

**장기기억 → 내 프로필**에서 직접 확인한 나의 선호와 적용 프로젝트를 관리합니다. 직접 작성한 내용을 확인한 뒤 저장하며, 일시적인 지시를 영구 선호로 자동 확정하지 않습니다. 사용을 중지한 선호는 AI 회상에서 빠지고 다시 사용할 수 있습니다. 이 기기의 현재 OS 사용자에게 암호화해 로컬 저장하며, 다른 기기나 계정 전체로 동기화하지 않습니다.

**내가 한 말**은 지시 원문과 연결된 결과를 보는 곳입니다. 원문을 확인해 필요한 선호를 직접 정리할 수 있으며, 수집한 대화를 자동 분석해 프로필을 만들지는 않습니다. 프로필의 선호도 현재 명시한 지시보다 우선하지 않습니다.

**도구 및 설정 → 아젠투지 설정**은 아젠투지(OPS)의 운영 기억과 준비·연결 상태를 관리합니다. **운영 기억 저장 후보**와 **저장된 운영 기억**은 이곳에 있습니다. 장기기억 화면의 **아젠투지 설정 열기**을 눌러도 같은 패널이 열립니다.

GitHub·Supabase 등 서비스 로그인은 **프로젝트 작업용 서비스 계정** 또는 헬프데스크의 **필수 계정** 단계에서 확인합니다. 브라우저 프로필, 서비스 로그인 계정과 아젠투지 설정은 각각 따로 관리됩니다.

## Google 설정이 처음이라면

**서비스 계정 → Google Workspace**에서 CLI 설치 상태와 기존 연결을 먼저 확인합니다. 이미 준비된 클라이언트 JSON이나 계정을 다시 만들 필요는 없습니다. JSON이 없다면 **Google 콘솔 · 클릭하며 따라하기**를 여세요. 프로젝트 선택 → 필요한 API → 동의 화면·테스트 사용자 → 데스크톱 앱 JSON → 앱 연결 확인을 한 단계씩 안내합니다. 기존 프로젝트에도 접힌 **API 설정 도움**이 있습니다.

사용자에게 보이는 순서는 **Google 설정 도움받기 → JSON 직접 첨부 → Google 로그인·연결 확인**입니다. 자주 쓰는 API 10개(Drive·Docs·Sheets·Slides·Gmail·Calendar·Forms·Tasks·People·Chat)를 안내하며 필요한 것만 켭니다. 현재 앱의 첫 연결은 Drive 읽기 권한을 사용합니다. API를 켰다는 이유로 메일·문서 접근이나 쓰기 권한이 생기지는 않습니다. 테스트 중인 외부 앱은 연결할 이메일을 각각 테스트 사용자에 넣어야 합니다. 어렵다면 **헬프데스크 도움받기**로 화면 이동과 이름·이메일 입력을 함께 진행할 수 있습니다(아래 절). 대안으로 가이드 아래의 동의 항목을 확인하고 **대안 · Codex 컴퓨터 사용 안내 복사**를 눌러 컴퓨터 사용 도구가 제공되는 Codex에 붙여넣을 수도 있습니다. 안내 준비는 AI 실행이나 계정 변경을 시작하지 않습니다.

CLI에는 **Desktop app** OAuth 클라이언트를 사용합니다. 생성 결과에 비밀값이 표시되기 전부터 사용자가 직접 생성·JSON 다운로드를 마치고 민감 화면을 닫습니다. 받은 JSON은 AI 대화에 올리지 않고 이 앱의 **Google Console 클라이언트 JSON**에서 직접 선택하거나 첨부 영역으로 드래그하세요. 앱은 OS 자격 증명 저장소에 보관합니다. 공식 Google 로그인 뒤 이메일과 실제 연결 결과를 확인해야 완료입니다.

컴퓨터 사용도 화면·열린 파일을 AI 문맥으로 처리할 수 있습니다. 브라우저로 진행한다는 이유만으로 비밀이 격리되는 것은 아닙니다. 안내는 JSON 파일·클립보드 내용·비밀번호를 읽거나 전달하지 않도록 제한하며 로그인·2단계 인증·OS 승인은 본인이 처리합니다. [Google 공식 CLI 안내](https://github.com/googleworkspace/cli#manual-oauth-setup-google-cloud-console) · [컴퓨터 사용 안내](https://learn.chatgpt.com/docs/computer-use#safety-guidance)

## 헬프데스크 도움받기 (에고라이트 또는 아젠투지브라우저)

Google 설정 도움, Google 따라하기, 계정 화면의 빠른 계정 추가, 헬프데스크의 서비스 계정·Google·AI 연결 단계에 **헬프데스크 도움받기** 버튼이 있습니다. 누르면 헬프데스크가 이 모드로 열리고, 시작 전에 다음을 직접 고릅니다.

- **브라우저**: 에고라이트(앱 안에 이 도움 전용 작업 공간) 또는 아젠투지브라우저(이 창 안의 전용 화면). 평소 쓰는 브라우저 탭은 건드리지 않습니다.
- **도움 AI**(브라우저와 따로): Claude는 도구 없이 실행해 이미 찾은 화면 요소 후보 중 하나를 번호로만 고릅니다. 페이지 내용·주소·이메일은 보내지 않습니다. Codex CLI는 읽기 전용 모드에서도 브라우저·MCP 도구를 끌 수 없어 쓰지 않습니다. **AI 없이**를 고르면 검토된 고정 단계만 진행합니다.
- **미리 정할 값**(Google): 기존/새 프로젝트, 동의 화면 앱 이름, 외부/내부 사용자. 비밀값은 없습니다.
- **적용 범위**: 계정 추가는 이 Mac 기본 계정과 프로젝트 연결을 바꾸지 않습니다. 프로젝트에서 시작하면 그 프로젝트에만 적용합니다. Mac 전체 전환은 계정 화면의 전환으로 직접 합니다.

진행 중에는 **잠시 멈춤 · 직접 하기 · 이어서 진행 · 도움 끝내기**를 언제든 누를 수 있습니다. 화면을 직접 조작하면 도움이 멈추고 기다립니다. 로그인·2단계 인증·최종 승인·**만들기** 같은 결정 버튼·클라이언트 JSON 생성과 다운로드는 직접 하며, 그 화면에서는 도움이 화면을 읽지 않습니다. 결과를 모르는 동작은 다시 보내지 않고 직접 확인을 요청합니다.

결과는 따로 표시합니다: 클라이언트 저장, 사용자 인증, **실제 CLI 사용 가능**. 실제 계정 검사가 통과한 경우에만 「실제 연결 확인됨」이라고 표시합니다. Codex·Claude는 공식 로그인 상태까지만 확인하며(새 AI 호출 없음) 「공식 로그인 확인됨 · 실제 응답은 확인하지 않았습니다」로 끝납니다. agy·Hermes·API 키·모바일 Google은 안내만 보여 주는 단계로, 끝나도 실제 연결을 확인하지 않았다고 표시합니다.

## iPhone 로그인과 Mac 연결

헬프데스크 첫 화면의 **iPhone 로그인·연결 도와주세요** 또는 **모바일 연결**을 누릅니다. 현재 Mac의 저장소 설정과 Supabase·Google Workspace CLI 인증 상태를 읽기 전용으로 확인합니다. 이를 모바일 인증 완료로 표시하지 않으며 실패한 조회는 **상태 확인 못함**으로 표시합니다. 각 항목에서 기존 CLI 인증·저장소·허용 이메일 화면으로 이어갈 수 있습니다.

- **이메일 코드**: 같은 Supabase의 Auth 사용자와 DB 허용 회원을 준비합니다. 코드는 기존 사용자에게만 요청하며 새 계정을 자동 생성하지 않습니다. 기본 메일러는 조직 팀 주소와 낮은 발송 한도로 제한되므로 다른 신규 사용자에게 보내려면 별도 SMTP를 설정합니다. 이미 메일을 받았다면 **이미 받은 코드 입력**으로 재발송 없이 로그인합니다. 429가 나오면 재발송을 반복하지 않습니다.
- **Google 로그인 · 선택**: Google Cloud의 **Web application** OAuth 클라이언트와 Supabase Google Provider를 준비합니다. Google 콘솔의 Authorized redirect URIs에는 Supabase Provider 화면의 callback을, Supabase의 Redirect URLs에는 iPhone 앱 복귀용 `agentstoz-mobile://auth/callback?state=*`를 추가합니다. 웹 포털도 쓰면 그 주소는 따로 허용하며 기존 주소는 보존합니다. Workspace CLI의 Desktop app JSON은 여기에 사용하지 않습니다.

Google 로그인 설정에서는 인증한 Supabase 관리 계정과 이 Mac의 저장소를 확인합니다. 같은 Google Cloud 프로젝트의 **웹 애플리케이션 JSON**을 앱에 직접 첨부하고 **변경 내용 검토 → 동의 → 적용**을 진행합니다. 기존 Provider가 준비되어 있으면 JSON을 다시 요구하지 않으며 필요한 iPhone 복귀 주소만 추가합니다. 다른 기존 클라이언트로 교체하거나 이메일·SMTP·회원·DB 설정을 변경하지 않습니다. 적용 응답이 끊기면 **이전 적용 결과만 확인**으로 조회하며 자동 재적용하지 않습니다.

Google 로그인을 지원하는 새 iPhone 앱은 기본 이메일 코드와 Google 버튼을 함께 제공합니다. 이전 TestFlight 1170은 이메일 코드만 제공하므로 앱 업데이트가 필요합니다. Supabase 등록 확인은 실제 iPhone 로그인 완료와 별도입니다. 본인이 로그인한 뒤 같은 앱 복귀·회원 접근·프로젝트 조회를 확인하세요.

**Google Workspace CLI 연결 돕기**는 Google 전용 준비 화면을 엽니다. 준비된 프로그램·클라이언트를 재사용하고 필요한 Google 단계만 이어갑니다. `Google 프로그램 준비 · 이어하기`는 Google Workspace CLI와 필요한 Node.js만 확인·준비하며, 완료 뒤 계정 연결 상태가 자동 갱신됩니다. 작성한 이메일은 유지합니다. **모바일 준비로 돌아가기**는 계정 연결 전에도 사용할 수 있습니다.

**iPhone 연결 QR 열기**로 Mac의 실제 QR 화면을 열고 같은 기기를 승인하세요. iPhone 로그인, 회원 접근·프로젝트 조회, Mac 제어 권한, 재연결 뒤 같은 작업 유지까지 각각 확인합니다. Supabase 저장소 자동 준비가 Auth 사용자·SMTP·Google Provider까지 자동 설정했다는 의미는 아닙니다. [Google 로그인 공식 설정](https://supabase.com/docs/guides/auth/social-login/auth-google) · [SMTP 공식 설정](https://supabase.com/docs/guides/auth/auth-smtp)

## iPad·iPhone에서 Mac 화면 연결

헬프데스크 첫 화면에서 **iPad·iPhone Mac 화면 연결**을 누르세요. AI 계정이 연결되지 않아도 **같은 Wi-Fi에서 처음 연결**, **“화면 등록 QR이 아닙니다”**, **LTE·외부에서 연결 준비**, **지운 기기가 Mac에 남아 있어요**를 골라 이전·다음 단계로 따라갈 수 있습니다. 질문 화면으로 돌아가도 작성 중인 질문은 유지합니다. AI 상담에도 같은 검토된 연결 안내를 제공합니다.

Mac의 **AgentsToZ Screen 등록 QR**은 프로젝트·워크룸 QR, Cloudflare 조직 등록과 구분합니다. 올바른 QR을 거절하면 양쪽 앱 버전부터 확인합니다. 지문·Face ID와 기기 확인은 본인이 처리하며 QR 원문이나 등록 비밀을 상담에 넣지 않습니다. 화면이 보인 뒤 클릭까지 Mac에 반영되는지 확인해야 실제 연결 확인입니다. 작은 대상은 트랙패드 입력 방식으로 조준할 수 있습니다.

Cloudflare 계정·터널은 대상 Mac에서 준비하고, 새 iPad·iPhone은 각각 Cloudflare One Agent 설치·같은 조직 로그인·첫 VPN 승인이 필요합니다. 사설망 경로를 지원하는 앱 버전에서 주소와 경로를 설정해야 합니다. 근거리 조작 성공·터널 Healthy·실제 LTE 조작은 서로 다른 확인 결과입니다. 이 안내를 열거나 단계를 넘겨도 계정 설정·기기 등록·원격 조작은 자동 실행하지 않습니다.

이 연결 도우미는 2026-10-26 이후 빌드한 설치본의 헬프데스크에 들어 있습니다. 첫 화면에 **iPad·iPhone Mac 화면 연결**이 보이지 않으면 앱을 업데이트하세요. [상세 연결 안내](../design/screen-control-2026-10-24/CONNECT-GUIDE.md)를 함께 참고하세요.

## 1. 프로그램 준비

**처음 설치해요 → 필요한 프로그램 한 번에 준비**를 누릅니다. 기본 선택은 Git·Codex·Claude Code·GitHub CLI·Supabase CLI이며 Node.js·npm 등 필요한 실행 환경도 함께 확인합니다. 이미 설치된 프로그램은 실제 실행을 확인하고, 빠진 프로그램은 차례로 준비합니다. 다른 도구는 선택 목록에서 바꿀 수 있고 Vercel CLI는 웹 배포가 필요할 때 추가합니다.

항목마다 진행 상태, 사용자 승인 대기와 실패 결과를 확인하세요. macOS 설치 승인창은 본인이 처리합니다. 중간에 앱을 닫거나 오류가 나면 **같은 요청 결과 보기**, **설치·실행 다시 검사**로 결과를 먼저 확인하고 준비를 이어갑니다.

AI 계정이 연결되지 않아도 기본 안내와 프로그램 준비부터 시작할 수 있습니다.

## 2. 필수 서비스 계정과 본인 저장소

**다음 · 필수 서비스 계정 연결**에서 GitHub와 Supabase를 준비합니다. 이 전체 첫 설치 경로에서는 두 서비스 계정이 필수이며, Vercel은 선택입니다.

- 계정이 없으면 **회원가입**으로 공식 사이트를 엽니다. 가입·이메일 확인·2단계 인증은 본인이 완료합니다.
- 계정이 있으면 **공식 화면에서 로그인·인증**을 누르고 사용할 계정을 확인합니다. 서비스에 따라 기기 코드나 확인 코드를 요구할 수 있습니다. 화면 안내대로 해당 공식 인증 흐름에서만 사용하세요.
- 브라우저 승인 뒤 앱에서 확인된 이메일과 CLI 연결 결과를 확인합니다. 응답이 늦으면 **같은 로그인 결과 확인**을 사용합니다.

Supabase에서는 인증된 본인 계정과 **무료 조직**을 고른 뒤 **이 계정에 무료 전용 저장소 만들기**를 누릅니다. 무료 조직 준비가 남았다면 안내된 공식 화면에서 마치고 **인증 계정·무료 조직 다시 확인**을 누르세요. 앱이 전용 프로젝트와 정본 DB 구성을 준비하고 실제 저장·조회 및 이 Mac 연결을 검사합니다. SQL 작성, DB 비밀번호 생성·복사, 관리자 키 붙여넣기를 신규 사용자가 따로 할 필요가 없습니다.

저장소 생성 응답이 늦거나 앱이 다시 시작되면 **같은 준비 결과 확인** 또는 **같은 저장소 준비 이어가기**로 진행합니다. 결과를 확인하지 않고 새 저장소 생성을 반복하지 마세요. 기존 앱 데이터를 사용하는 추가 Mac은 **기존 저장소 연결 확인**으로 이동합니다. 유료 조직·기존 저장소를 새 전용 저장소처럼 자동 변경하지 않습니다.

프로젝트 작업용 서비스 계정과 **앱 데이터 저장·기기 동기화** 연결은 목적이 다릅니다. 프로젝트 계정만 추가했다고 기존 앱 데이터 저장소가 바뀌지는 않습니다. 로컬 프로젝트 관리만 사용하는 경로는 [공개 설치본 안내](MAC-INSTALL.md)를 참고하세요.

## 3. 사용할 AI 연결

**다음 · AI 연결**에서 Codex 또는 Claude 하나를 선택하고 공식 인증을 마칩니다. **인증·연결 다시 확인**으로 상태를 확인한 뒤 질문 화면으로 돌아갑니다. 이미 유효한 계정이 있으면 해당 연결 상태부터 확인합니다.

## 4. 사용 질문과 첫 업무

**도움받기**에서 첫 프로젝트 등록, 워크룸, 프로젝트 기억, 기기 연결 사용법을 질문합니다. AI 미연결 상태에서는 기본 안내를 제공합니다. AI 답변은 선택한 본인 Codex·Claude 계정으로 실행됩니다.

헬프데스크는 앱의 준비 버튼과 공식 인증 화면을 안내합니다. 실제 프로젝트 파일 수정·명령 실행·업무 결과 확인과 기억 저장은 해당 프로젝트 워크룸에서 진행합니다. [업무와 기억의 흐름](METHODOLOGY.md)을 참고하세요.

## 2026-10-22 검증 범위

v1181 후보는 Developer ID 서명과 앱·DMG 각각의 Apple 공증·티켓 첨부·Gatekeeper 검사를 통과했습니다. 현재 Mac에서 앱 데이터와 CLI 설정을 격리해 Supabase 실제 인증, 전용 DB 자동 생성과 정본 58개 테이블·RLS, 재시작 뒤 실제 앱 RPC 저장·조회·삭제와 인증 유지를 확인했습니다. 정확한 최종 DMG의 격리 실행·재시작·연속 동작 및 개발 소스 접근 차단 검사는 40개를 통과했습니다.

GitHub 공식 브라우저 인증과 이메일 확인·OS 자격 증명 저장·기기 기본 CLI 연결을 완료했고, 최종 서명 앱 재시작 뒤 실제 공식 CLI 연결도 통과했습니다. v1181의 현재 Mac 격리 검증 범위에서 로컬 배포 준비를 완료했습니다. 현재 GitHub의 공개 다운로드는 v1165이며, v1181 바이너리는 아직 공개 업로드하지 않았습니다. 새 Mac·별도 macOS 사용자·GUI 첫 설치와 48시간 연속 운영을 검증했다는 의미는 아닙니다. 설치 파일은 [공개 릴리스](https://github.com/intenet1001-commits/AgentsToZ-public/releases)에서 해당 버전의 상태를 확인하세요.


## AI에 Mac 창 하나 맡기기

연결된 AI에 “컴퓨터 유즈를 연결해 줘”라고 요청한 뒤 **도구 및 설정 → 컴퓨터 유즈**를 연다. AI가 알려 준 연결 이름과 맡길 창·작업을 선택하고 **이 창 허용 요청**을 누른다. Control 앱에서 같은 대상과 요청 내용을 본인이 확인하고 승인한다. 처음에는 Control 도우미 연결 준비·손쉬운 사용 권한을 확인해야 한다. 각 창의 제어 허용은 최대 10분이며 AI 앱에 따라 여러 대화가 한 연결을 공유할 수 있다. 도우미를 여는 동작은 승인이 아니다.

실행 중에는 사람이 쓰는 마우스와 키보드를 우선하고, 지원하는 접근성 버튼·입력란만 조작한다. 캔버스나 지원하지 않는 요소는 사람이 이어서 처리한다. 결과가 불명확한 입력은 자동으로 다시 보내지 않으며, 현재 앱 상태를 직접 확인한 뒤 검토를 완료한다. **허용 종료**나 도우미의 **모두 중단**으로 종료할 수 있다. iPad의 화면 등록·Cloudflare 망 경로·외부 AI 앱의 에포트 자동 변경은 각각 별도 준비·검증 대상이다.
