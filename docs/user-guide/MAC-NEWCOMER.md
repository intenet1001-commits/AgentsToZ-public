# 새 Mac에서 아젠투지 시작하기

이 안내는 새 온보딩이 포함된 후속 Mac 테스트 빌드용입니다. 헬프데스크의 전체 구성과 오류 대처는 [헬프데스크 사용법](HELPDESK.md)을 참고하세요. 현재 공개 v1165 DMG의 동작은 [v1165 설치 안내](MAC-INSTALL.md)에서 확인하세요. 설치 파일의 버전과 포함 기능을 먼저 확인해 주세요. Apple Silicon Mac용이며 최소 macOS 13입니다.

1. 받은 DMG를 열고 `AgentsToZ_byCS.app`을 `Applications` 폴더로 끌어다 놓습니다. 업데이트라면 먼저 앱과 진행 중인 작업을 종료하세요.
2. Applications에서 앱을 열고 헬프데스크의 **처음 설치해요**를 선택합니다. 다시 열려면 **아젠투지 호출** 창 오른쪽 위의 **헬프데스크**를 누르세요.
3. **필요한 프로그램 한 번에 준비**를 누릅니다. Git·Node.js·npm·Codex·Claude Code·GitHub CLI·Supabase CLI를 순서대로 확인하고 빠진 프로그램을 준비합니다. 항목별 진행상황을 보며 macOS 설치 승인창을 처리하세요. 웹 배포를 원하면 Vercel CLI도 선택할 수 있습니다.
4. **필수 계정**에서 GitHub와 Supabase를 연결합니다. 계정이 없으면 **회원가입**, 이미 있으면 **공식 화면에서 로그인·인증**을 누르세요. 서비스의 공식 화면에서 계정 선택, 이메일 확인, 2단계 인증과 접근 승인을 마칩니다. 확인 코드가 표시되면 화면의 복사·입력 안내를 따르세요. Vercel 가입·인증은 선택입니다.
5. 인증한 Supabase 계정과 본인의 무료 조직을 확인하고 **이 계정에 무료 전용 저장소 만들기**를 누릅니다. 가입 중 무료 조직 준비가 남았다면 안내된 공식 화면에서 마친 뒤 **인증 계정·무료 조직 다시 확인**을 누르세요. 앱이 저장공간과 필요한 구성을 준비하고 실제 저장·조회와 이 Mac 연결까지 확인합니다. DB 비밀번호·SQL·연결 키를 따로 입력하지 않습니다.
6. **다음 · AI 연결**에서 사용할 Codex 또는 Claude 계정을 공식 인증합니다. 둘 중 하나를 연결하면 헬프데스크에 질문할 수 있습니다.
7. 헬프데스크에서 첫 프로젝트·워크룸 사용법을 질문하거나, 안내된 앱 화면에서 첫 프로젝트를 시작합니다. 실제 작업은 프로젝트 워크룸에서 진행합니다.

비밀번호와 2단계 인증은 공식 서비스 화면에서, Mac 설치 승인은 macOS 창에서 직접 처리하세요. 비밀번호·토큰·연결 키를 헬프데스크 대화에 붙여넣지 마세요.

중간에 멈췄다면:

- 설치 승인 대기라면 macOS 창을 확인하고 같은 설치 결과를 다시 확인합니다. 이미 설치된 프로그램은 다시 설치하지 않습니다.
- 로그인 응답이 늦으면 **같은 로그인 결과 확인**을 사용합니다.
- 저장소 준비가 중단되면 **같은 준비 결과 확인** 또는 **같은 저장소 준비 이어가기**를 사용합니다. 새 저장소를 중복으로 만들 필요가 없습니다.

기존 저장소가 있는 추가 Mac은 **기존 저장소 연결 확인**으로 이동하세요. 이 안내의 새 전용 저장소 만들기는 첫 설치용입니다. 유료 조직이나 기존 저장소를 자동으로 변경하지 않습니다.
