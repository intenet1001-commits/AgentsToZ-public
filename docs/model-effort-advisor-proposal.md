# 작업별 모델·추론 수준 권유안

2026-09-07 사용자 제안과 후속 구현 요청. 장기기억 에이전트 v20의 Claude/Codex 회상 스킬과 앱 없는 환경용 지침에 1차 권유 정책을 적용했다. 별도 앱 추천 엔진이나 자동 모델 변경은 제공하지 않는다.

현재 Mac 우선 개선의 구체적인 배치는 [상세 설계의 구현 모델 표](design/README.md)에 있다. 핵심 구현은 Astra 높음, 계약이 확정된 일반 UI·문서는 Sol 중간, 설계·출하 전 교차 검토는 Astra Ultra를 권유한다. 이 프로젝트 개발 권유를 앱 사용자들의 AI 실행 기본값으로 자동 적용하지 않는다.

## 목적

현재 작업에 충분한 모델과 추론 수준을 권유해 비용과 대기 시간을 줄이고, 복잡한 판단에서 필요한 검토 깊이를 확보한다. 모델 종류와 추론 수준은 독립적으로 취급한다.

## 입력과 출력

- 실행 표면이 확인해 준 모델·추론 수준·관측 시각을 우선한다. 사용자가 직접 알려 준 값은 출처를 구분한다. 알 수 없는 설정은 추측하지 않는다.
- 작업 규모, 변경 범위, 검증 실패, 재시도 횟수, 보안·데이터 변경 경계를 근거로 삼는다. 단순 토큰 사용률 상승만으로 모델 상향을 권하지 않는다.
- 권유는 유지/하향/상향, 한 문장 이유, 적용할 단계, 되돌릴 조건으로 구성한다. 현재 표면에서 지원 여부가 확인된 설정만 특정한다.
- 단순 반복 편집·검증 완료 후 정리에는 하향을 고려한다. 원인 불명 반복 실패·동시성·권한 격리·데이터 이관 설계에는 상향을 고려한다.
- 자동으로 설정을 변경하지 않는다. 사용자의 무시·거절을 존중하고 동일 작업 단계의 동일 권유를 반복하지 않는다.

## 장기기억과 비용

검증된 작업 유형별 결과만 소량 보존한다. 예: “설정 파일 변경은 기존 테스트로 검증했고 중간 추론으로 충분했다.” 성공 여부를 모델 이름만으로 인과 추정하지 않는다. 프롬프트 원문·credential·전체 대화는 이 기능에 복제하지 않는다.

추가 AI 호출을 매 턴 발생시키지 않는다. 에이전트가 이미 가진 작업 문맥과 로컬 구조화 신호를 우선하고, 앱 표시 상태는 활성 세션에 한정한 제한된 캐시로 관리한다. 새 전역 폴러나 무제한 권유 이력을 만들지 않는다.

## 검증할 경계

확인 불가 모델, 실행 중 설정 변경, 지원하지 않는 추론 수준, 같은 권유 반복 억제, 사용자의 유지 선택, 오래된 모델 목록, 여러 프로젝트 동시 실행과 프로젝트 기억 오염을 검증한다. 초기 도입은 권유 표시와 검증된 결과 기록만 제공하고 비용 절감 수치를 단정하지 않는다.
