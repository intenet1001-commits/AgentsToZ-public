# 자주 쓰는 프롬프트 보관함

Supabase가 설정된 데스크톱과 로그인한 모바일 작업 공간은 같은 프롬프트 보관함을 사용한다.
한 개인 Supabase 배포의 허용 회원 사이에서 공유하며, 회원별 개인 보관함으로 분리하지 않는다.
기존 기기 내 암호화 보관함은 그대로 보존하고 ‘이 기기 프롬프트 가져오기’로 명시적으로 가져온다.
Supabase 설정이 없는 데스크톱은 기존 기기 내 보관함을 사용한다.

- `portmgr_prompt_guides`는 최대 100개·1 MiB의 공유 목록이다. 회원 RLS와 RPC 권한을 적용하며
  익명 사용자는 읽거나 쓸 수 없다. 공유 본문은 DB에 저장되며 종단간 암호화를 주장하지 않는다.
- `portmgr_prompt_guides_read`와 `portmgr_prompt_guides_save`는 revision으로 동시 수정을 검사한다.
  늦게 저장한 기기가 다른 기기의 수정·삭제를 덮어쓰지 않는다. 응답이 불확실하면 재조회 후 비교한다.
- 모바일은 제목·본문 검색, 목록에서 바로 복사, 고정 항목 복사를 지원한다. 보관함을 다시 열면
  공유 목록을 새로 읽으며 저장하지 않은 초안은 유지한다. 모바일 입력은 16px, 버튼은 최소 44px다.
- 복사는 클립보드 작업만 수행한다. 원격 AI 실행 권한이나 터미널 전송을 대신하지 않는다.

`bun test ./tests/shared-prompt-guides.test.ts`는 실제 PostgreSQL 엔진에서 회원 경계와 저장 충돌을 검사한다.
로컬 Vite 실행 후 `node tests/shared-prompt-guide-smoke.mjs http://127.0.0.1:19111`은 외부 요청을
차단한 합성 보관함으로 모바일 저장·검색·복사·초안 보존·바깥 영역 닫기를 검사한다.

# 장기기억 단말 목록

장기기억 Push/Pull 보고는 `portmgr_register_memory_device`로 현재 데스크톱의 누락된 목록 행을
보충한다. 기존 표시 이름과 프로젝트 마지막 Push 시각은 변경하지 않는다. 이미 다른 ID에 연결한
옛 설치와 원격 호스트(등록 해제 포함)는 새 데스크톱으로 등록하지 않는다.

기억 카드와 단말 필터는 동일한 대표 이름 선택 규칙을 쓴다. 명시적인 identity alias가 있을 때만
설치를 한 대로 집계하며, 대표 ID의 이름을 옛 설치 이름보다 우선한다. 이름이 같다는 사실만으로
같은 물리 기기로 확정하지 않는다. 실제 동일 기기로 확인한 후 가역적인 alias RPC를 사용하고,
기존 리비전·상태·프로젝트 행은 지우거나 다시 쓰지 않는다.
