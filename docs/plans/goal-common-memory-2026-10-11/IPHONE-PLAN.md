# iPhone 13 공통기억·MCP 실기 검증

사용자 요청: 실제 iPhone 13에서 페르소나에 따라 편의성을 점검하고 MCP까지 검증·수정한다. 연결된 기기는 iPhone 13 Pro Max(iPhone14,3), iOS 26.3이다.

## 완료 기준

1. 기존 로컬 메타 기억을 보존하고, 같은 클라우드의 목표별 기억을 모바일 기록 화면에서 조회·관리할 수 있다. 원본 프로젝트 기억은 변경하지 않는다.
2. 클라우드 전체 관리 동의는 기존 Mac 로컬 메타 기억·프로젝트 터미널 동의와 별도로 받는다. 권한 철회·호스트 변경·미지원 호스트·응답 유실을 확인한다.
3. 처음 사용자(이름·목표·원본 선택), 여러 프로젝트 사용자(A+B/B+C), 신중한 편집자(목표 변경·충돌·미확정 결과), 작은 화면/저시력 사용자(16px 입력·44pt 조작·키보드·스크롤) 시나리오를 수행한다.
4. 앱과 MCP가 같은 서비스·원본·불변 게시본을 사용하며 실제 stdio 요청으로 목록·원본 조회·추천·회상·재시도·거부를 검증한다. 테스트용 데이터와 기존 사용자 데이터를 구분한다.
5. 물리 iPhone의 실제 WKWebView 결과와 격리 서버/시뮬레이터 결과, 설치 앱/출하 소스 결과를 각각 기록한다. Wi-Fi·백그라운드·재시작 복구를 확인하고 사용자의 다른 앱 사용은 방해하지 않는다.

## 실행 순서

- 게시된 깨끗한 작업트리를 재사용한다. canonical 기억은 기존 main에서 회상하고 tester 조정은 같은 세션에서 이미 완료된 것을 재사용한다.
- 현재 quick 기준선을 확인한다. 모바일 권한·같은 크기 제한/공유 전송 예산·페이지 조회와 편집/미확정 결과 처리 구현 및 회귀를 추가한다.
- 기존 페르소나·모바일·MCP·iOS 계약 검사 후 실제 iPhone 시험으로 결함을 재현·개선한다.
- 출하 소스 검증·GitHub 반영·Mac/아이폰 업데이트가 필요한 경우 기존 안전 빌드/설치 경로를 따른다. 새 기기 제어 권한은 테스트 대상 연결에만 적용한다.
