# 운영 프로필 구현·검증 기록

2026-09-14. 사용자 요청: 총괄 운영 기억을 AI/현재 폴더와 독립시키고, 개인 다른 Mac 및 공개 앱의 첫 실행에서 준비되게 구현하며 충분히 테스트한다.

## 구현

- 사용자 전용 프로필 store, 기존 Control 정체성 유지, 빈 사용자 자동 준비, 여러 후보 선택, Private 저장소 검증·복원·등록·Pull.
- 파일 lease, 준비 기록, 연결 전환 기록으로 동시 실행과 중단 복구. 기존 키 소실/기억 불일치/복원 충돌에서 빈 프로필을 만들지 않음.
- 공통 MCP 3개 추가(v1.13.0), 사용자 capability 인증, 제한된 회상, 후보 멱등성, revision을 검증하는 검토·저장.
- 기존 workspace dispatcher/lease와 기억 엔진 재사용. 로컬 저장과 백업 분리. 시작/조회 때 원격 갱신, 충돌/오프라인 로컬 유지.
- Codex·Claude·Hermes·agy 설정 어댑터 및 전역 호출 규칙 v2. Hermes custom home/기존 개별 프로필 모델 보존.
- 온보딩·도구·AI 작업에서 운영 프로필 화면. 저장 후보·최근 기억 시각·연결 상태·관제 정책. Control 폴더 없는 관제 실행.
- Private 복원 seed의 공개 snapshot 제외.

## 검증

- 격리된 실제 Bun API + MCP: 프로젝트 0개 사용자 준비 → 프로필 조회 → 후보 제출 → 화면 관리 API 검토 → 저장 → 재회상. 다른 사용자 키 거부, 응답에 경로/키 미포함.
- 도메인 회귀: 기존 기억 유지·이름 변경, 재시작, 복원 실패, 동시 시작, 키 소실, revision 충돌, 불확실 저장 영수증 재확인, 기존 Control 연결 전환의 4개 중단 지점, 후보 선택.
- Private 추가 Mac 시뮬레이션: 원격 저장소 메타데이터/clone/Pull 전송은 fixture, 기억 엔진·디스크·등록은 실제. 원래 memoryId 유지 및 반복 clone 방지.
- 동기화 회귀: 후속 원격 결정 수신, 충돌/오프라인 로컬 보존, 60초 재사용, 동시 갱신 합류.
- 연결 설정 회귀: Claude의 다른 MCP 보존, Hermes 기본/custom/개별 프로필 유지, Codex/agy 공식 CLI 인자·설정 재조회, 기존 충돌 설정 보존. AI 모델 응답을 가장하지 않음.
- 실제 React App + 격리 API fixture: 첫 프로필 준비, 프로젝트 미생성, 정책 변경, 후보 검토 저장, AI 작업 이동. 화면 overflow/오류 확인.
- AI 작업 Playwright: 기존 9개 시나리오 및 Control 폴더 없는 프로필 관제 1개 통과. 불확실 재시도·초안 보존·탭 전환 회귀 포함.
- 전체 `bun run verify`, 최종 빌드/설치 결과는 아래 후속 기록으로 구분한다.

## 별도 검증 경계

현재 체크아웃의 자동 테스트는 다른 물리 Mac에서 실제 Pull·시작한 증거가 아니다. 공개/TestFlight 배포 완료나
4개 AI의 실제 모델 응답 완료도 별도 결과가 있어야 표시한다. 새 공개 사용자 프로필은 처음에 로컬 저장이며,
다른 Mac과의 기존 Control 연결 및 백업이 준비된 경우에만 동기화를 제공한다.

## 전체 검사와 실제 CLI 확인

- 최종 `bun run verify`: TypeScript 0 오류, Bun 4,263 pass / 0 fail, Rust 58 pass / 0 fail.
- 별도 집중 회귀: 39 pass / 0 fail. Hermes 일부 프로필만 연결되어 있을 때 새 프로필을 추가하는 경우도 보강해 통과.
- 컴파일된 MCP 1.13.0: stdio 초기화와 실제 API의 격리 프로필 조회 성공, memoryId 일치.
- Claude 실제 모델 호출: 두 읽기 도구만 허용한 일회성 테스트에서 3턴, 권한 거절 0회, 예측값을 프롬프트에 넣지 않은 profileId/memoryId가 fixture와 일치. 회상 0건도 정확히 반환.
- Codex 비대화형 read-only 검사: 두 MCP 도구 발견·호출 시도는 확인했으나 CLI의 무승인 정책에서 도구 승인이 필요해 거절됨. 실제 회상 성공으로 기록하지 않음.
- Hermes 별도 테스트 home: 기존 모델 선택을 유지하고 인증 파일은 복사하지 않음. 런타임이 `OAuth access token has expired` / HTTP 401을 반환. 재로그인 전 실제 AI 회상 완료는 미확인.
- CLI 시험용 프로필은 폐기 가능한 합성 기억이며 실제 사용자 운영 기억에 테스트 후보를 넣지 않음.
- 공개 snapshot dry-run: 비밀값 검사 통과, private-only 130개 경로 제외. 앱의 다른 물리 Mac/TestFlight 설치 결과와 구분.

- agy 비대화형 plan 검사: MCP action에 대한 승인이 필요하고 headless 모드가 질문할 수 없어 거절됨. 권한을 무제한 허용하는 옵션을 적용하지 않았으며 실제 회상 성공으로 기록하지 않음.
