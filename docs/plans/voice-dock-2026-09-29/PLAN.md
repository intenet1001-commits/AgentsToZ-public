# 아젠투지 음성 도크 — 대화 상대 전환 · 상대별 저장 · 이중 자막 (2026-09-29)

## 사용자 결정 (VOC 2026-09-29)

- 본부장 비유: 총괄(부서장)을 통해 시킬 수도, 프로젝트 담당자(부서원)와 직접 말할 수도 있다.
  - A. 총괄이 워크룸을 제어 — 대화 상대는 총괄. 음성 기록은 OPS.
  - B. 담당자로 전환 — 대화 상대는 그 프로젝트 AI. 음성 기록은 그 프로젝트.
- 「아젠투지 호출」은 **항상 보이는 플로팅 캐릭터**(Mac·iPhone). 페이지가 바뀌어도 사라지지 않는다.
- 캐릭터 아래 상태 한 줄: 「총괄 응답중」 / 「<프로젝트> · <AI> 담당자 응답중」, 그 아래 선택 버튼.
  버튼 = 음성으로 말한 것과 같은 전환.
- 동의는 한 번. 이후 캐릭터를 누르면 곧바로 음성 시작(패널 없이).
- 제공자·모델 변경은 도크의 ⚙.
- 담당자에서 총괄로 돌아오면 OPS 기록에 한 줄 표식(요약 AI 호출 없음).
- 자막: 옵션(끄기 / 원문 / 원문+통역). 기본 = 원문+통역 — 한국어로 말하면 한국어+영어, 영어로 말하면 영어+한국어.

## 설계

### 호스트 (`voiceSessionHost.ts`, `voiceRuntimeBinding.ts`)
- 새 동작: `partners`(총괄 + 실행 중 워크룸, 최대 8), `partner`(수동 전환 — ops 또는 특정 워크룸 세션),
  `caption`(한 줄 통역). 옛 호스트는 「지원하지 않는 음성 요청」으로 거절 → 클라이언트는 조용히 숨긴다.
  응답 새 키(`partners`,`caption`)는 새 동작에만 실린다 — 옛 클라이언트는 그 동작을 부르지 않으므로 안전.
- 상대별 저장: OPS 세션이 담당자로 전환되면 그 워크룸 범위의 **구간 세션**(history begin, 워크룸 identity)을
  열고 이후 발언을 거기로 보낸다. 총괄로 돌아오거나 다른 담당자로 바꾸거나 음성을 끝내면 구간을 닫고,
  OPS 기록에 「[아젠투지 기록] <라벨> 직접 대화 N발언 → 프로젝트 음성 세션에 저장」 표식을 남긴다.
  발언의 소속은 전사 완료 시점이 아니라 **항목이 생긴 시점**(item created/committed)의 상대로 정한다.
- 수동 전환은 초안·전송 중이면 거절(음성 도구와 같은 규칙), 모델에게 「화면에서 전환했다」는 문맥을 알린다.
- 모델 지시문은 실제 저장 위치를 말한다(예전엔 담당자 연결 중에도 「프로젝트 쪽으로 이어진다」고 잘못 말했다).
- 통역: 세션 제공자의 텍스트 모델(OpenAI `gpt-5.4-mini` reasoning none / Gemini `gemini-3.5-flash-lite`,
  2026-09-29 실측 0.8~1.5초). 세션당 상한, 4,000바이트 상한.

### 클라이언트
- `voiceMediaClient`: `partners()`, `switchPartner()`, 자막 줄(원문·통역·역할) 상태, 자막 설정.
- `AgentsToZVoiceDock`: 앱 최상위 플로팅. 캐릭터 + 상태 + 상대 버튼 + ⚙ + 종료. 기존 헤더 칩 대체.
- 워크룸 음성 버튼은 두지 않는다(VOC 2026-09-29/30 — 음성 입구는 도크 하나). 상대 전환은 도크의 상대 버튼과 ⋯뿐이고, 워크룸 입력칸 아래 `VoiceSentReceipt`(`workroom-voice-sent`)는 아젠투지가 그 워크룸에 보낸 내용만 보여 준다. OPS가 허용되지 않은 휴대폰은 도크를 누르면 열린 워크룸의 AI와 음성으로 대화한다.
- iPhone 포털: 같은 도크를 포털 루트에 둔다.

## 검증
- 단위/통합: 전환·구간 저장·표식·수동 전환 거절 규칙·partners 목록·caption(가짜 번역기)·프로토콜 정규화·옛 호스트 폴백.
- 브라우저 fixture: 도크 표시(모든 탭), 원탭 시작, 상대 버튼 전환, 자막 두 줄.
- `bun run verify` 전체, 설치 앱 빌드 후 Mac 실기, iPhone은 사용자 실기.
