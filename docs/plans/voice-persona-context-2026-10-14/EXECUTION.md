## 구현 계약

- 데스크톱의 OPS 음성은 고정된 독립 창 하나가 소유한다. 메인 창에 같은 마이크
  클라이언트를 다시 마운트하지 않는다. 웹·휴대폰의 기존 도크는 유지한다.
- 창 URL은 고정 표면만 허용한다. 음성 창의 runtime 프록시는 음성 경로만 허용하고
  창 닫기는 마이크 해제 후 해당 창만 닫는다. 음성·워크룸 세션과 원본 저장 권한은 유지한다.
- 공통기억은 장기기억 ID와 원본 리비전이 정본이다. GitHub 프로젝트 복제 UI는
  공통기억 화면에서 제거하며 기존 데이터·서버 계약은 삭제하거나 이관하지 않는다.
- 페르소나 후보는 프로젝트별 변경·기억의 주제 메타정보·검사 범위·실패 근거로 제안한다.
  자동 제안은 AI 호출·테스트 실행·카탈로그 활성화가 아니다. 검토자가 실제 검사를 연결하고
  현재 카탈로그/맥락 리비전에 대해 확정한다. 이름만 있는 역할은 판정하지 않는다.
- 기존 카탈로그와 검사·지침은 보존한다. 중복 후보, 재전송, 오래된 검토, 경로 교체,
  카탈로그가 없는 프로젝트와 실행 중 변경을 검증한다. 공통 러너는 새 버전으로 배포한다.

  초기 개발 과정의 구형 후보 메타정보는 로컬 ignored 백업으로 보존하고 현재 형식으로 재제안했다.
- 공통 러너 1.6.0, MCP 계약 1.40.0. 현재 프로젝트의 공통 지침과 metadata도 정확한 setup revision으로
  갱신했으며 프로젝트 검사 설정·카탈로그·원본 기억은 보존했다.

전체 검증 후 음성 컨테이너 CSS 선택자와 백업 digest 경로의 작은 수정은 영향받은 화면 검사·
SHA-256 회귀·타입 검사로 추가 확인한다. 위 물리 화면 결과는 실제 생성/연결/복원 경로의
fixture 스냅샷이며 설치된 개인 앱이나 최종 TestFlight 다운로드의 통과를 뜻하지 않는다.
