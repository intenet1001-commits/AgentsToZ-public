# 검색 기준선: 검토용 합성 사례 10건

2026-10-29 · 소스 기준 `e9a2051df25d1a79e4ca215b15db074e62ffd305`

이 문서는 기존 키워드·일지 FTS 검색을 비교하기 위한 첫 실험이다. 아래 사례와 기대 결과는 **사람이 아직 검토하지 않은 합성 초안**이다. 실제 기억을 전송하거나 임베딩 모델을 사용하지 않았다. 사용자 기억·OPS 기억·공통 기억의 운영 결과, 실제 검색률 또는 성능을 대표하지 않는다.

## 실행과 관찰

```sh
bun scripts/research/hybrid-search-baseline.ts
```

실행기는 합성 문서 10개와 질문 10개를 실제 정제 기억 검색 함수 및 일지 FTS/scan fallback 함수에 전달한다. 일지 인덱스는 실행마다 임시 폴더에 만들고 삭제하며, 본문 없는 결과 보고서는 OS 임시 폴더에 기록하고 경로를 출력한다. 네트워크와 외부 제공자는 사용하지 않는다.

| 검토 항목 | 초안 기대 | 2026-10-29 관찰 |
| --- | --- | --- |
| 오류 코드·짧은 한글·기술 식별자 | 정확한 합성 항목 반환 | 각각 반환; 두 글자 `백업`은 scan fallback |
| 원문 표현이 없는 재서술 | Enter 관련 합성 항목 반환 | 정제 기억과 일지 모두 해당 항목을 상위 5개에서 찾지 못함 |
| 충돌·수집 경계·시퀀스 | 관련 합성 항목 반환 | 각각 상위 5개에 포함 |
| 프로젝트 범위 | 허용된 합성 항목만 반환 | 다른 프로젝트의 합성 항목은 반환되지 않음 |
| 충돌 중인 기억 | 후보를 반환하되 주의 표시 | 정제 기억 후보에 주의 표시 |
| 존재하지 않는 고유 질의 | 근거 없음 | 두 검색 모두 결과 없음 |

초안 기대 항목은 각 검색에서 **9/10** 사례에 포함됐다. 이는 이 작은 합성 자료에서의 관찰이며 검색 정확도나 벡터 검색의 개선 효과가 아니다. 재서술 사례는 실제 정답 근거를 사람이 검토한 뒤 평가 자료에 포함해야 한다. 한두 개의 단어가 일치한 후보의 의미적 타당성이나 답변 근거 여부도 이 실행기만으로 판정하지 않는다.

## 다음 검토

1. 10개 질문의 기대 항목·보류 조건을 실제 정본의 출처, 버전, 교정·삭제 상태에 비춰 검토한다. 실데이터는 별도 허용 범위 안에서만 사용한다.
2. 문맥이 비슷하지만 반대 조건인 기록, 두 글자 한국어, 오류 코드, 오래된 결정, 권한이 없는 프로젝트 및 교정·철회를 포함해 별도의 최종 평가 세트를 만든다.
3. 검색률·오답 후보·범위 위반과 지연을 독립적인 자료에서 측정한다. 같은 합성 자료로 모델을 조정하고 최종 효과를 주장하지 않는다.
4. 모델·임베딩 저장소나 외부 서비스는 평가 설계와 데이터 범위가 검토되기 전 도입하지 않는다. 이 문서는 운영 DB 변경이나 사용자 기억 원문 외부 전송의 승인이 아니다.

실행기는 정제 기억과 일지의 **검색 함수만 직접 호출**한다. 앱의 전체 권한 검사, 버전에 결속된 교정, 클라우드 공통 기억, 자연어 답변의 근거 판정까지 검증하지 않는다. 전체 검색 계약과 연구 순서는 [기존 연구 인계](../handoffs/2026-10-23-supplementary-vector-search-research.md)를 따른다.
